When a CSV workflow makes sense

A batch workflow is useful when the contact data already exists in a spreadsheet. Instead of creating one QR code at a time, an office manager can prepare a team directory; an event organizer can prepare attendee contacts; or a school can prepare staff badges. Each row becomes its own vCard payload and QR code.

Use a standard vCard QR code when the contact details are stable. If the destination needs to change after printing, review the difference between static and dynamic QR codes before committing to a large print run.

Set up the CSV correctly

Put the field names in the first row and one contact in each subsequent row. The bulk generator includes fields for full name, phone number, email, company, job title, and website. You can leave optional values blank, but every contact needs a name for a useful vCard.

  • Keep one contact per row; do not combine multiple people in one cell.
  • Use a complete phone number, including the country code, when a number may be scanned internationally.
  • Use CSV UTF-8 when exporting names with accents or non-English characters.
  • Check that emails and websites are in their own columns rather than mixed into notes.

Export from Excel or Google Sheets

The uploader accepts .csv files. In Excel, choose File > Save As and select CSV UTF-8 (Comma delimited). In Google Sheets, use File > Download > Comma-separated values (.csv). The related Excel-to-CSV guide covers the spreadsheet-preparation path in more detail.

Upload, map, preview, and download

  1. Open the bulk QR generator and upload the saved CSV file.
  2. Match each CSV column to the appropriate vCard field. Review the name mapping especially carefully.
  3. Use the preview to check one contact before generating the full batch.
  4. Download the ZIP file, which contains PNG QR codes named from each contact.
  5. Scan a few finished codes on a phone before sending anything to print.

Before you print the batch

A valid QR code can still fail if it is too small, low contrast, or placed against a busy background. Keep a quiet margin around the code, avoid stretching it, and test a representative print at the intended size. Use the QR code printing guide for practical size and DPI checks. For individual cards, see the business card QR code guide.

Privacy and limits

The bulk tool processes the CSV in the browser; the contact details are not uploaded to the site's servers. That makes it a good fit for routine contact-card preparation, but it does not replace an organization's own approval process for sharing employee contact details. Keep a copy of your source CSV so you can recreate a batch when contact information changes.

Frequently asked questions

Can I use Excel instead of CSV?

Prepare the spreadsheet in Excel if you prefer, then save it as CSV UTF-8 before uploading. The bulk uploader accepts CSV files.

Can I add a logo to every bulk QR code?

The CSV bulk workflow is for creating vCard QR codes from contact rows. For an individual branded code, use the logo QR code generator.

What if a contact changes after printing?

Static vCard details are embedded in the code, so create and print a replacement when the data changes. If editability is essential, consider an editable QR code before printing.
