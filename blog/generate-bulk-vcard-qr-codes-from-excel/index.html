Why start in Excel?

Excel is a convenient place to clean a roster before any QR codes are created. It lets you review names, email addresses, phone numbers, and job titles in one view. The generator creates a separate vCard QR code for each row, so catching inconsistent data before generation prevents a costly reprint later.

If you already have a CSV, go directly to the bulk vCard QR codes from CSV guide. This page focuses on the Excel-to-CSV step that the uploader needs.

Use one contact per row

  • Include country codes in phone numbers when contacts may be used internationally.
  • Keep emails and websites in their own columns.
  • Leave optional fields blank instead of placing placeholder text in the cell.
  • Check names carefully: they are used to identify the generated files.

Export Excel as CSV UTF-8

  1. Open the completed workbook in Excel.
  2. Select File > Save As.
  3. Choose CSV UTF-8 (Comma delimited) (*.csv).
  4. Save a copy and keep the original workbook unchanged.

CSV UTF-8 helps preserve accents and non-English characters. The bulk uploader accepts .csv, not a native .xlsx workbook.

Upload, map, and validate the batch

  1. Open the bulk QR code generator and upload the saved CSV.
  2. Map each spreadsheet column to the matching vCard field; double-check full name and phone number.
  3. Preview a contact before generating all codes.
  4. Download the ZIP, which contains named PNG QR codes for the batch.
  5. Scan a few QR codes on a phone before printing the complete run.

Print checks that prevent rework

QR codes need enough clear space and contrast to scan reliably. Do not stretch the image, place it over a detailed photograph, or reduce it below a tested size. The contact QR code printing guide covers practical size and DPI checks; the business-card guide helps with card placement.

Privacy and when to use an editable QR code

The bulk tool processes the CSV in the browser, so the contact data is not uploaded to the site's servers. Static vCard data is a strong fit when it will remain stable. If you expect to change the destination after printing, compare static and dynamic QR codes before ordering a large print run.

Frequently asked questions

Can I upload an Excel file directly?

Export the Excel sheet as CSV UTF-8 first. The uploader accepts CSV files, which keeps the import predictable across browsers.

Which details should each row include?

Use one contact per row. Full name, phone number, email, company, job title, and website can be mapped to vCard fields.

Should I test before printing a full batch?

Yes. Preview the mapping, scan a few generated codes on a phone, and check the intended print size before producing all cards or badges.
