# vCard QR Code Generator Skill

## Name

Create vCard QR payload

## Description

Generate a standard vCard payload for QR code encoding from contact fields such as full name, organization, title, phone, email, website, address, and notes.

## Invocation

- REST: `POST https://vcardqrcodegenerator.com/api/v1/vcard`
- MCP: `tools/call` with `name` set to `create_vcard_payload` at `https://vcardqrcodegenerator.com/mcp`
- Schema: https://www.vcardqrcodegenerator.com/openapi.json

## When To Use

Use this skill when the user wants to create or automate a digital business card QR code.
